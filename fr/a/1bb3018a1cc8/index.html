Le Kazakhstan met à jour les règles d'examen du permis de conduire, simplifiant les procédures pour les candidats

Le ministère de l'Intérieur du Kazakhstan a mis en œuvre de nouvelles règles pour l'immatriculation des véhicules et les examens de conduite, effectives depuis le 9 octobre. Les procédures sont simplifiées, éliminant les inspections séparées pour les modifications de véhicules. Les candidats peuvent repasser les examens échoués le jour ouvrable suivant. Après trois tentatives infructueuses, les repassages ultérieurs seront payants. Les résultats positifs de l'examen théorique ne seront plus annulés si l'examen pratique n'est pas réussi.
