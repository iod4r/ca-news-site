Saint-Pétersbourg interdit aux migrants de travailler dans les magasins, salons et installations sportives

Les autorités de Saint-Pétersbourg, en Russie, ont interdit aux migrants titulaires de permis de travail de travailler dans des secteurs spécifiques. L'interdiction concerne les emplois dans le commerce de détail, les salons de coiffure, les instituts de beauté et les installations sportives. Cette mesure restreint les opportunités d'emploi pour les travailleurs étrangers dans ces domaines.
