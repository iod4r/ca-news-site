Sept élèves tués dans une explosion près d'une école dans la province afghane de Kunar

Sept élèves ont été tués et jusqu'à 99 autres blessés dans une explosion survenue le 28 novembre près d'une école dans la province de Kunar, dans le nord-est de l'Afghanistan. Les premières informations suggèrent que l'explosion s'est produite dans un entrepôt de produits explosifs appartenant à des sociétés minières. Les autorités enquêtent sur l'incident.
