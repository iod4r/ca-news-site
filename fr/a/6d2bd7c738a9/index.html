Le Kirghizistan étend les subventions sur le carburant à l'essence ECO-93

Le Cabinet kirghiz a inclus l'essence ECO-93 dans son programme de subventions sur le carburant pour stabiliser les prix du marché. Le diesel pour "Kyrgyzkomur" a été fixé à 92,85 soms par litre. Ces mesures visent à maîtriser les coûts d'extraction et de transport du charbon, évitant ainsi les hausses de prix pour les consommateurs.
