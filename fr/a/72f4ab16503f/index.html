Almaty Clarifie les Réglementations pour les Établissements des Rues Gastronomiques Face aux Plaintes des Résidents

La corporation socio-entrepreneuriale d'Almaty a clarifié les réglementations pour les cafés et restaurants situés dans les immeubles résidentiels, en particulier ceux des nouvelles rues gastronomiques. Le statut de "corridor gastronomique" n'est pas une base pour fermer automatiquement les entreprises, mais elles doivent respecter les ordonnances sur le bruit et les lois sur la vente d'alcool. Les plaintes des résidents concernant les nuisances, comme le bruit des clients ivres, seront traitées par les autorités compétentes.
