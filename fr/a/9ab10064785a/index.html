Le ministère kazakh de l'Économie dément les rumeurs d'une taxe sur les intérêts des dépôts bancaires

Le ministère de l'Économie nationale du Kazakhstan a clarifié qu'il n'y avait aucun projet d'introduction d'une taxe sur les intérêts perçus des dépôts bancaires individuels. Le ministère a indiqué que les dispositions actuelles du code fiscal exemptent ces revenus de l'impôt sur le revenu des personnes physiques.
