ChatGPT Introduira des Discussions Privées Protégées par Code PIN ou Données Biométriques

OpenAI introduira une fonctionnalité de «Discussions Privées» pour ChatGPT, permettant aux utilisateurs de protéger leurs conversations avec un code PIN ou des données biométriques. Cette fonctionnalité vise à empêcher d'autres personnes de voir les conversations personnelles, en particulier lors de l'utilisation du service dans des lieux publics. Ces discussions privées seront stockées dans une section séparée et cachée.
