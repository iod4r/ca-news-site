Les propriétaires de Beeline Kazakhstan négocient la création d'une banque

Les propriétaires de l'opérateur de télécommunications kazakh Beeline, le groupe Veon, sont en consultation technique avec le régulateur concernant la création d'une banque au Kazakhstan. Veon a l'intention d'entrer sur le marché kazakh avec une banque numérique d'ici la fin de 2027, dans le but de concurrencer les grands groupes financiers. La société discute avec le régulateur de diverses formes de représentation sur le marché.
