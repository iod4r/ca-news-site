Le Kazakhstan interrompt les expéditions de pétrole suite à une attaque de drone ukrainien, puis reprend le flux

Le Kazakhstan a temporairement interrompu les expéditions de pétrole brut via le pipeline Atyrau-Samara suite à une attaque de drone ukrainien contre une raffinerie de pétrole russe. Le ministère de l'Énergie a annoncé la reprise du flux pétrolier quelques heures plus tard. Le Kazakhstan prévoit de produire 99 millions de tonnes de pétrole cette année, dépassant potentiellement les quotas de l'OPEP+.
