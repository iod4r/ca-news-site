Le Kazakhstan invite les entreprises allemandes à investir dans les technologies numériques

Le Kazakhstan encourage les entreprises allemandes à investir dans les technologies numériques, les centres de données, l'efficacité énergétique, l'infrastructure cloud et la cybersécurité. Le président Tokayev a souligné les technologies financières et la «ville intelligente» Alatau City comme des domaines prometteurs pour le partenariat. Le Kazakhstan vise à tirer parti de son écosystème financier numérique développé pour une expansion régionale.
