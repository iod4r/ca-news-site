Le Kazakhstan évaluera le bien-être familial via une carte numérique à partir de 2027

À partir du 1er janvier 2027, le Kazakhstan mettra en œuvre de nouvelles règles pour sa Carte Familiale Numérique afin d'évaluer le bien-être social des familles sur la base des données des systèmes numériques étatiques et autres. Le système recevra et mettra à jour automatiquement les informations sur les revenus, les charges financières, les actifs, l'emploi, la composition familiale et l'état de santé. Les agences gouvernementales devront transmettre les données mises à jour dans un délai d'un jour ouvrable.
