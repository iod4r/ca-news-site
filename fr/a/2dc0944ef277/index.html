Le pont de Crimée attaqué deux fois en deux jours, le trafic interrompu

Le trafic sur le pont de Crimée a été temporairement interrompu après une deuxième attaque dans la nuit du 17 novembre. Les spécialistes évaluent les dégâts. La première attaque a eu lieu dans la nuit du 16 novembre. Les autorités russes attribuent les attaques à l'Ukraine, qui n'a pas officiellement commenté. Le Comité d'enquête russe a ouvert une enquête pénale pour terrorisme.
