Un vol Flydubai à destination d'Israël dérouté vers l'Arabie Saoudite après une alerte d'hijacking

Selon les médias israéliens, un vol Flydubai de Dubaï vers Tel Aviv a été dérouté vers l'Arabie Saoudite après avoir émis des signaux d'urgence, y compris un code de détournement. L'avion aurait transmis le code 7700 (urgence générale) puis brièvement le code 7500 (intervention illégale). Des chasseurs israéliens ont été dépêchés. Des sources sécuritaires israéliennes ont ensuite indiqué que la menace de détournement était écartée, suggérant un différend entre les pilotes.
