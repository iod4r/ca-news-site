Le Kazakhstan lancera une application pour surveiller les risques d'incendie dans les habitations

Le Kazakhstan développe une application mobile appelée « Tumar 112 » pour surveiller les risques d'incendie dans les immeubles résidentiels. Actuellement en phase pilote dans la région d'Abai, l'application permettra l'enregistrement électronique des inspections, la consignation des dangers d'incendie avec photos et géolocalisation, et la création d'une base de données unifiée pour la prise de décision opérationnelle.
