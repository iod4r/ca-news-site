Le Kazakhstan impose un étiquetage numérique obligatoire pour les compléments alimentaires à partir de septembre 2026

Le Kazakhstan a mis en place un étiquetage numérique obligatoire pour les compléments alimentaires (BAD) produits à partir du 1er septembre 2026. Un agent IA identifiera les produits non enregistrés. Les consommateurs pourront vérifier l'authenticité via l'application mobile Naqty Onim. L'objectif est d'accroître la transparence du marché et de protéger les consommateurs.
