L'Ouzbékistan fait face à une potentielle violation de données affectant les deux tiers de la population

Un groupe de pirates informatiques nommé Butterfly affirme avoir obtenu les données personnelles de près de 27 millions de citoyens ouzbeks à partir d'une base de données gouvernementale. Le groupe a exigé que les autorités se conforment à leurs conditions, sous peine de voir les données vendues. Le gouvernement ouzbek n'a ni confirmé ni infirmé le piratage présumé, qui pourrait inclure des noms, adresses et informations biométriques.
