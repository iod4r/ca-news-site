Une nouvelle système pour aider les secours dans les montagnes d'Almaty est en phase de test

Un nouveau système de sécurité est en cours de test à Almaty pour aider les secouristes à localiser les personnes dans les zones montagneuses, même sans accès mobile ou internet. L'appareil AG Tag utilise la navigation par satellite pour transmettre les coordonnées aux services de secours, se mettant à jour toutes les deux secondes. Un bouton SOS permet aux touristes d'envoyer un signal d'urgence.
