Le Kazakhstan suspendra les taxes d'accise accrues sur les carburants à partir de 2027

Le Kazakhstan suspendra les taux d'accise accrus sur les produits pétroliers pour les fournisseurs en gros à partir de 2027. L'Association PetroMining a déclaré que le taux précédemment augmenté de 95 % nuirait à l'économie des exploitants de sous-sol. Le gouvernement a décidé de suspendre la mesure après que l'association et les producteurs de pétrole ont présenté les risques.
