    Le Code du Travail de l'Ouzbékistan Interdit désormais le Harcèlement Sexuel au Travail

    L'Ouzbékistan a officiellement interdit le harcèlement sexuel sur le lieu de travail en modifiant son Code du Travail. Le président Shavkat Mirziyoyev a signé les modifications le 13 novembre, alignant la législation du pays sur les normes internationales du travail. Le nouvel article définit le harcèlement sexuel et oblige les employeurs à garantir un environnement exempt de harcèlement. La discrimination fondée sur la couleur de peau et les opinions politiques est également désormais interdite.
