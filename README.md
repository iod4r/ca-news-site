# ca-news-site

Ce dépôt reçoit le HTML généré automatiquement par le job Cloud Run
`rss-ingest`, quatre fois par jour. Porkbun Static Hosting le déploie.

**N'éditez rien ici à la main** : le prochain passage du job écrasera vos
modifications. Les gabarits sont dans le dépôt applicatif.

La source de vérité des données est la base SQLite dans Cloud Storage,
pas cet historique Git.
