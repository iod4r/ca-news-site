В Астану по воздуху доставили 1 тыс. овец из Австралии для экс-менеджера КТЖ

Катарская компания доставила по воздуху 1,1 тыс. племенных овец из Австралии в Астану для компании «Ерейментау-Астык-2014», принадлежащей экс-управляющему по закупкам КТЖ Айдару Нигметову. Это первый этап проекта по закупке 4 тыс. овец в рамках программы льготного кредитования «Береке».
