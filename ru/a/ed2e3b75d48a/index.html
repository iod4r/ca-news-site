Узбекистан вводит переводы денег по номеру телефона через Систему быстрых платежей

Центральный банк Узбекистана утвердил правила осуществления денежных переводов между физическими лицами через Систему быстрых платежей по номеру телефона. Система связывает банковский счет с номером мобильного телефона, при этом к одному счету может быть привязан только один номер. Управление привязкой осуществляется через Национальную базу данных вкладчиков.
