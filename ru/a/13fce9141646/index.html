Казахстан пересмотрит список бирж для исламского финансирования

Казахстан рассматривает возможность исключения Bursa Malaysia из перечня международных товарных бирж для исламского финансирования. Соответствующий проект постановления правительства опубликован на сайте "Открытые НПА". Малазийскую биржу предлагается исключить из-за несоответствия критерию нового закона о банках, который требует, чтобы товарная биржа осуществляла деятельность в государстве с суверенным рейтингом не ниже 'А'.
