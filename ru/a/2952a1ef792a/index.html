Face ID и код из eGov помогли подтвердить 160 млн приемов у врачей в Казахстане

В Казахстане для предотвращения ложных записей в медкарты проверяют, действительно ли пациент был на приеме. С помощью распознавания лица подтвердили 53,9 млн приемов, а с помощью кода из eGov Mobile — 106,1 млн. Систему запустили в 2024 году в Астане, с января 2025 года она поэтапно внедряется по всей стране.
