Kyrgyzstan Develops Interactive Map of State Property

Kyrgyzstan has developed an interactive map of state property as part of its digitalization efforts. The modernized state property registry, launched in collaboration with the 'Kyzmat' State Enterprise, provides real-time data on state assets acquired since independence. The map and registry will be fully operational from January 2027.
